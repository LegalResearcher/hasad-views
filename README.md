# Hasad Views

يسحب منشورات قناة `@hasadalyoum` ويعالج كل الروابط الجديدة التي يكتشفها في التشغيل عبر الحسابات الـ16 بالتوازي، بلا حد عددي للروابط.

## كيف تتداخل الدفعات

- تُختار جميع الروابط الجديدة المكتشفة بالترتيب من الأقدم إلى الأحدث، ثم تضاف إليها روابط آخر دفعتين سابقتين.
- تُرسل الحسابات الـ16 الطلبات على المجموعة نفسها. روابط الدفعة السابقة تُعاد معالجتها حتى لو نجحت في التشغيل السابق.
- تُحفظ آخر ثلاث دفعات في `state/previous_batch_links.json`. عند وصول روابط جديدة، تُعالج الدفعة الجديدة مع أحدث دفعتين سابقتين.
- إذا لم تظهر روابط جديدة، تُعالج آخر ثلاث دفعات معًا. إذا كان مجموعها أقل من 15 رابطًا، تُستكمل بروابط أقدم من الأرشيف حتى 15 متى توفرت، وتُعاد المجموعة في كل تشغيل بلا روابط جديدة.
- عند أول تشغيل، تُعتبر كل المنشورات الظاهرة التي لم تُسجل سابقًا روابط جديدة.
- تُسجل محاولات كل حساب ورابط في ملفات `state/`؛ وأخطاء الروابط الجديدة تُحسب بحد أقصى ثلاث محاولات. إعادة الدفعات السابقة مقصودة وتتجاوز منع تكرار النجاح. عند غياب الجديد، يستهدف التشغيل 15 رابطًا سابقًا على الأقل؛ أي 240 طلبًا على الأقل عبر الحسابات الـ16 إذا توفرت الروابط، وقد يكون العدد أكبر. ولا يوجد حد أعلى لعدد الطلبات في التشغيل.

## التشغيل والإعداد

يشغّل GitHub Actions سير العمل عبر `workflow_dispatch` بمهلة قصوى قدرها 360 دقيقة. وفق إعداد المشروع، يُفترض أن يرسل Supabase `pg_cron` هذا الحدث كل 10 دقائق. ويمكن تشغيله يدويًا من تبويب Actions > Hasad Views > Run workflow.

يلزم تعريف أسرار GitHub Actions الـ32: لكل حساب من 1 إلى 16، `SITE_USERNAME_N` و`SITE_PASSWORD_N`. كما يلزم سر `github_actions_token` في Supabase Vault، بصلاحية تشغيل Actions للمستودع.

سير عمل `Hasad Views - Manual Link Retry` يعيد الرابط المحدد عبر الحسابات الـ16 بالتوازي؛ أي حتى 16 طلبًا، بكمية 100 لكل طلب. يعتبر التشغيل ناجحًا فقط إذا نجحت الحسابات كلها.

## تصفير الحالة

حذف الملفات داخل مجلد `state/` (ما عدا `.gitkeep`) يعيد النظام إلى حالة جديدة وينسيه الروابط والدفعة السابقة والنتائج المسجلة. لا تصفّر الحالة إلا إذا كنت تقصد ذلك.

## ملاحظة

المستودع عام وملفات `state/` محفوظة فيه؛ لا تضع بيانات دخول أو مفاتيح سرية في هذه الملفات. بيانات الدخول يجب أن تبقى في GitHub Actions Secrets.
